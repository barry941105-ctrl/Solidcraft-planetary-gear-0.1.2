planetary-gear-0.1.2 A SolidCraft plugin that can generate planetary gears, requiring the tooth profile to be involute. It allows setting the number of sun gear teeth Zs, planet gear teeth Zp, and ring gear teeth Zr, which satisfy the relationship Zr = Zs + 2Zp. Only two of these parameters need to be set, and the third will be automatically completed. It also supports setting the number of planet gears, gear module, pressure angle, gear thickness, and gear type (spur/helical/double helical). For helical or double helical gears, the helix angle and direction can be specified. The outer diameter of the ring gear can also be set. Additionally, it automatically calculates the transmission ratios between the sun gear, planet gears, and ring gear (pairwise) and displays them in the plugin. The generated gear set is an assembly, with each individual gear being a single solid body.
